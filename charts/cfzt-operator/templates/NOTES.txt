CRD upgrade caveat (D23):

  CRDs ship in `charts/cfzt-operator/crds/` per Helm 3 native install-only
  behaviour. `helm upgrade` does NOT modify installed CRDs.

  - ArgoCD users rendering the chart and applying via Application sync: CRDs
    are not upgraded on chart bump. Matches D15 delete-and-recreate policy.
  - Flux users: set `install.crds: Create` and `upgrade.crds: CreateReplace`
    with care; again matches D15.

  For breaking CRD changes (D15: v1alpha1 permits them without conversion
  webhook): export CloudflareTunnel, CloudflareExposure, and
  CloudflareAccessPolicy manifests, uninstall, install new version, reapply.
